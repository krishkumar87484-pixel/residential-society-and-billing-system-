# Submission checklist - target: next week

## 1. GitHub repository
- [ ] Create a public repository with a clear name such as `residential-society-billing-system`.
- [ ] Upload the full project folder from this package.
- [ ] Add the actual Review 2 presentation.
- [ ] Add the final presentation.
- [ ] Run `python run.py` and test the main pages before the final commit.
- [ ] Add a short description and keep the README at the repository root.

## 2. Working prototype
- [ ] Open the Dashboard.
- [ ] Add a test flat and resident.
- [ ] Generate a bill for a month not already in the sample data.
- [ ] Record a partial payment, then another payment to settle the bill.
- [ ] Confirm the bill status changes from `UNPAID` to `PARTIAL` to `PAID`.
- [ ] Create a complaint and update it to `In Progress` and `Resolved`.
- [ ] Open Reports and confirm the balances/collections match the sample transactions.

## 3. Five-minute video and public Drive link
- [ ] Record the screen while narrating the demo script in `5-minute-demo-script.md`.
- [ ] Keep the video close to five minutes and make all text readable.
- [ ] Upload the video to your personal Google Drive.
- [ ] Set General access to **Anyone with the link - Viewer**.
- [ ] Open the link in an incognito/private browser window to verify that access works without signing in.
- [ ] Add the video link and final presentation link to both versions of the link document.
- [ ] Commit the completed documents to GitHub.

## 4. Final report hardcopy
- [ ] Review `reports/Final-Report-Draft.docx` and correct any details required by the faculty.
- [ ] Add faculty/supervisor name, university/department details and all team-member names if required.
- [ ] Add screenshots captured from the final working prototype.
- [ ] Confirm report title, project number, roll number, spelling and page layout.
- [ ] Print, bind if required, and submit the hardcopy to ma'am.
